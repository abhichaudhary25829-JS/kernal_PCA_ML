# Kernel PCA Based Machine Learning Classification

## 📌 Project Overview

This project investigates the use of Kernel Principal Component Analysis (KPCA) for dimensionality reduction of network traffic data, followed by machine learning classification.

The project evaluates multiple machine learning algorithms with different KPCA component values and test-size configurations.

## 🎯 Objectives

- Perform data preprocessing on network traffic datasets.
- Apply Kernel PCA for dimensionality reduction.
- Evaluate multiple machine learning classification algorithms.
- Compare model performance using different KPCA configurations.
- Generate confusion matrices and performance metrics.
- Identify the effect of dimensionality reduction on classification performance.

## 📂 Dataset

The project uses network traffic datasets containing CIC-IDS style network activity.

The dataset files used in the project are:

- Tuesday-WorkingHours.pcap_ISCX.csv
- Wednesday-workingHours.pcap_ISCX.csv
- Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
